# Bike Sharing Data Analysis Dashboard 🚲

## Deskripsi
Proyek ini adalah analisis data dari "Bike Sharing Dataset" untuk memenuhi proyek akhir dalam alur belajar Data Analysis. Dashboard ini menampilkan tren penyewaan dan pengaruh cuaca terhadap jumlah pengguna.

## Struktur Direktori
- **/dashboard**: Berisi file utama untuk dashboard Streamlit dan data yang sudah dibersihkan.
- **/data**: Berisi dataset mentah (day.csv dan hour.csv).
- **notebook.ipynb**: File analisis data lengkap dari tahap Wrangling hingga Visualisasi.
